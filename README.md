**Project Information:**
Project title: HomeHub
Project description: HomeHub is a home service booking management platform that connects homeowners with service providers. Homeowners can manage their homes, browse available home service, check provider availability, and create bookings. Service providers can manage their services, availability, and customer bookings. Administrators manage users, providers, categories, services/system activity.

**USER STORIES:**
1. Register account: 
As a new user 
they want to register an account 
so that they can use HomeHub.
2. Verify email:
As a registered user
they want to verify their email
so that they can access HomeHub's features.
3. Login:
As a verified user
they want to log in
so that they can securely have access to their account.
4. Manage profile:
As a user
they want to view and update their profile 
so that their personal data/info stays current.
5. Manage homes:
As a homeowner
they want to manage their homes
so that they can choose where a booked service should be performed.
6. Browsr services:
As a homeowner
they want to browse and search available services
so that they can find the home service they need.
7. Manage providers profile:
As a provider
they want to manage their profile
so that homeowner can know/learn about their business.
8. Manage services:
As a provider
they want to manage the services they offer
so that homeowners can book them.
9. Manage availability:
As a provider
they want to define their availability 
so that homeowners know when they can provide a service.
10. Create booking
As a homeowner
they want to book a service for one of their homes
so that the provider can perform the requested service.
11. Manage booking status:
As a provider
they want to update the status of a booking
so that the homeowner knows its progress.
12. Cancel booking:
As a homeowner
they want to cancel their booking
so that they can release a timeslot they no longer needed.
13. Reset password:
As a user
they want to reset a forgotten password
so that they can regain access to their account.
14. Manage users:
As an admin
they want to deactivate users 
so that they can prevent inappropriate accounts from accessing HomeHub.
15. Manage categories:
As an admin
they want to manage service categories
so that HomeHub's services remain organized.
16. Receive notifications:
As a user
they want to receive notifications when booking event occur
so that they know when their booking changes.
17. View audit activity:
As an admin
they want important system action recorded 
so that activity can be reviewed when necessary.
